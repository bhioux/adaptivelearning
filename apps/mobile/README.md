# Adaptive Learning Platform — Mobile App (Flutter)

Scaffolded in Phase 2. The mobile app will be built from `ui-prototype/mobile/`
(phone-framed interactive prototypes, EdX + Coursera aesthetic) into Flutter
`lib/screens/*` with `@al/shared` types.

Tracked structure:

```
apps/mobile/
  pubspec.yaml
  lib/
    screens/          # one per ui-prototype/mobile/*.html
    main.dart
```

Run `flutter pub get` and `flutter run` when Phase 2 begins.
