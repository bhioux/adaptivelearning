Which sequence theorem applies when terms are squeezed between two null sequences?

Hint — uses 1 energy point

Recall that the squeeze theorem applies when two outer sequences converge to the same limit L and a third sequence lies between them near that point.

Correct: the Squeeze Theorem — if aₙ ≤ bₙ ≤ cₙ for large n and lim aₙ = lim cₙ = L, then lim bₙ = L.
