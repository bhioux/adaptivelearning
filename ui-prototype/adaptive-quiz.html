Which sequence theorem applies when terms are squeezed between two null sequences?

Given sequences aₙ = 1/n², bₙ = 2/n², and cₙ = 1.5/n²…

Hint — uses 1 energy point

Recall that the squeeze theorem applies when two outer sequences converge to the same limit L and a third sequence lies between them near that point. Try selecting the option that matches that definition.

Correct: the Squeeze Theorem — if aₙ ≤ bₙ ≤ cₙ for large n and lim aₙ = lim cₙ = L, then lim bₙ = L. The Outer sequences converge to zero, so bₙ → 0 as well.
